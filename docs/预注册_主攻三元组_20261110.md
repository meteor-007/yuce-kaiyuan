# 预注册：主攻三元组 200 期前瞻检验

预注册日期：2026-11-10
开始期：第 2026300 期
目标：200 个可评估期（预测在开奖前登记、开奖后结算）

## 一、假设

- H0：主攻三元组「≥2 码」命中率 = 15.26%（3 码组在 80 选 20 下的精确超几何概率）。
- H1：> 15.26%（单侧）。
- 显著性水平：α = 0.01。

## 二、规则冻结

- 选号规则：`kl8_report.compute_picks` → `kl8_methods.select_main_groups` / `build_triples`，以 2026-11-10 当前代码版本为准。
- 规则指纹：`SHA256(kl8_core.py + kl8_methods.py + kl8_report.py + TRIPLE_WEIGHTS + H_DEF)` 的前 16 位，写入 `output/forward_test/pre_registered_20261110_meta.json`。
- 任何改动（权重、特征、评分、选组、历史截断逻辑）都会改变指纹，登记函数会拒绝继续。
- 如确需修复代码：先停止本预注册并保留已完成记录，再新开一份新的预注册；不得在原预注册上改规则。

## 三、样本与登记

- 从第 2026300 期起，每日在开奖前用当天 20 个点位运行 `kl8_daily.py`。
- 登记内容：期号、日期、20 个点位、主攻组（成员/中心/场分/T1 或 T2 分层）、规则指纹、登记时间。
- 预测登记后不可修改；同一天重复运行只允许相同点位/相同组的幂等登记。
- 开奖同步后由 `kl8_daily.py` 自动结算；未登记的期不计入。
- 目标 200 个可评估期（有主攻组且已结算）。不设提前停止，不因中途结果调整规则。

## 四、终点与判定

- 主要终点：主攻组「≥2 码」率 vs 15.26%，单侧精确二项检验，α = 0.01。
- 关键次要终点：
  - 按期聚类的 95%CI；
  - 前 100 期与后 100 期均 > 15.26%；
  - T1 核心 / T2 防守分层；
  - 3 连全中率 vs 1.39%；
  - 去重号命中率 vs 25%。
- 成功判定（缺一不可）：
  1. 主要终点 p < 0.01；
  2. 前后半均 > 15.26%；
  3. 按期聚类 95%CI 下界 > 15.26%。
- 任一不满足 → 未通过，关闭「主攻三元组可预测」这一方向。
- 无论结果如何都完整报告；不因中途结果提前停止或改规则。

## 五、先验预期

现有证据中的边界信号为主攻组 17.98% vs 15.26%（置换 p≈0.03，但全候选池 15.70%、前后半 19.18%→16.76% 衰减、BH-FDR q≈0.15）。先验预期回归 15.3%。本检验是一次性证伪，不是确认性研究。
