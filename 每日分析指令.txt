快乐8「点位+遗漏」每日分析指令（可复用模板）
================================================================================
使用方式
  1. 复制本文件为当天的工作副本（或直接在副本中替换占位符）。
  2. 只替换「本期参数」中的 <...>；任务清单、执行校验、验收标准不要删改。
  3. 若「目标期」「目标日期」留空，脚本会自动按最新开奖推导，并在控制台回报。

【本期参数】
--------------------------------------------------------------------------------
运行日期：<YYYY-MM-DD>
本期点位（20 个）：<01 02 03 ... 80>
目标期：<YYYYNNN；不确定则留空，默认=同步后最新开奖期 +1>
目标日期：<YYYY-MM-DD；不确定则留空，默认=最新开奖日次日>
点位来源备注：<可选，例如外部图表/方法版本>

控制台输出总体要求
================================================================================
- 详细展示各分析模块的推荐结果与关键计算依据，排版清晰、对齐美观。
- 先给结论，再给明细；任何数据告警、异常、降级都必须显式说明。
- 标准报告与详细报告同时落盘到 output/reports/。

任务清单
================================================================================

1. 同步最新开奖数据
--------------------------------------------------------------------------------
- 执行：python kl8_sync.py --quick
- 核对同步后的最新期号、日期与开奖号码；确认「昨天」的开奖已入库。
- 若福彩官网与备用源都失败：明确说明失败原因，使用本地现有历史继续分析，
  并在最终结论顶部标注「数据截至第 X 期」，不得静默使用旧数据。

2. 录入点位
--------------------------------------------------------------------------------
- 号码：<本期点位>
- 校验：必须是 1-80 内不重复的 20 个号码。
- 推荐执行（已同步后）：
    python kl8_daily.py --no-sync --raw-points "<本期点位>" --full-print
- 若目标期/日期不确定，显式指定：
    python kl8_daily.py --no-sync --raw-points "<本期点位>" --period <目标期> --date <目标日期> --full-print
- 脚本会把点位写入 daily_points.txt 顶部；期号默认 = 最新开奖期 +1，日期默认 = 最新开奖日次日。
- 写入前核对：目标期必须晚于最新开奖期；若目标期已开奖，脚本会拒绝写入。
- 若脚本报「同期已有不同日期」：说明同步滞后或期号算错，先修正同步/期号，
  不要用 --force 绕过；--force 只用于确认要修正历史点位。
- 写入后核对：daily_points.txt 中昨日点位行必须仍然存在且未被覆盖；
  目标期行必须恰好 1 行，且日期/号码与本次录入一致。

3. 深度复盘昨天的推荐情况
--------------------------------------------------------------------------------
- 复盘对象：昨天的最新开奖期，以及昨日系统给出的主攻三元组。
- 展示真实开奖(20)、形态统计（大小比、奇偶比、和值、跨度、重号、连号集群）。
- 核算昨日 20 个核心点位的命中数/命中号码，以及扩展集合的命中数。
- 核算昨日主攻三元组的实战命中（≥2 码算命中；3 连全中单独标注）。
- 给出复盘结论：哪些判断正确、哪些偏差、偏差原因是什么。

4. 执行所有预测模块并详细输出
--------------------------------------------------------------------------------
- 10 个分析模块逐一输出关键中间结果与 Top 号码：
  ① 连号集群三元组
  ② 马尔可夫 P01/P11 转移
  ③ 斐波那契/黄金分割
  ④ SVD + 共现条件概率
  ⑤ 复变傅里叶周期
  ⑥ 图网络共现拥挤度
  ⑦ 波动率聚类
  ⑧ 熵值均衡监控
  ⑨ 微积分八区双态
  ⑩ 对抗博弈 λ
- 汇总输出必须包含：
  H1–H7 评分仪表盘 Top5、顺势榜/对冲榜、宏观趋势、风险预警与应对、
  《趋势简报》决策树、终极推荐清单、40 日命中率面板。
- 使用 --full-print 把详细版附录 A–F 一并打印到控制台。
- 报告落盘：output/reports/分析报告_<YYYYMMDD>.txt 与 _详细.txt。

5. 代码与逻辑检查
--------------------------------------------------------------------------------
- 先检查本次运行涉及的数据读取、期号匹配、历史截断、评分合成与报告生成链路。
- 运行测试：python -m pytest -q；记录本次通过项数并与上次基线比对（当前基线 23 项）。
  若测试数变化，更新基线并在报告中注明。
- 若发现代码或逻辑问题：先列出问题清单、影响范围和修复方案，再修复；
  修复后必须重新运行并跑测试验证，必要时补回归测试。
- 不得通过篡改数据、硬编码结果、跳过校验等方式让结果「好看」。
- 最终必须证明功能正常、结果可复现。

6. 命中率与优化判断
--------------------------------------------------------------------------------
- 读取 [8] 40 日命中率面板；必要时用 python kl8_backtest.py --periods 300 复核。
- 用同口径的 100 日、200 日窗口，以及 300 期三元组 walk-forward 再复核。
- 调整门槛（必须同时满足，缺一不可）：
  · 40/100/200 日主攻去重命中率的 95%CI 下界都高于 25%；
  · 300 期三元组 groups 的 95%CI 下界高于其随机基线；
  · 全历史 edge scan（python kl8_edge_scan.py）存在通过 BH-FDR 的信号。
- 新模块/新特征必须先预注册：未来 ≥200 期样本外、单侧 α=0.01、规则冻结、无中途调参；
  同时报告按期聚类 CI、置换检验与 BH-FDR 校正。
- 若没有：明确写「不调整」，不调权重、不加模块、不为改而改。
- 若确认某模块过于复杂且对最终交付（集群三元组）没有出口：先说明影响范围，
  再移除，并跑回归测试。
- 结论口径：95%CI 覆盖随机基线（25%）即视为没有可验证优势，不得表述为「显著提升」。

7. 最终输出：只要集群三元组，可复制格式
--------------------------------------------------------------------------------
- 最终结论只保留集群三元组相关内容，不混入单号五码、两码备防等其它推荐。
- 先列本期主攻三元组（T1核心 / T2防守），每组一行，注明中心号与场分。
- 再附「纯净可复制清单」：清单必须与 [6] 主攻组完全一致，不能用候选 Top8 代替。
  每行一组，格式如 24-25-26；无序号、无表头、无表格线、无其它文字，
  放在控制台输出的最后，直接可复制。
- [7] 的候选 Top8 只作对照，不进入最终清单。

执行校验（逐条确认）
================================================================================
[ ] 开奖历史最新期、目标期、本期点位日期三者一致。
[ ] daily_points.txt 中昨日点位行未被覆盖；目标期行恰好 1 行。
[ ] 报告 [6] 主攻组与最终纯净可复制清单完全一致。
[ ] 报告 [0]–[8] 齐全；0 条数据告警、0 个 Traceback。
[ ] python -m pytest -q 全过（当前基线 23 项）。
[ ] 命中率结论与 40/100/200 日、300 期 walk-forward、edge scan 三处证据一致。

验收标准
================================================================================
- 同步后的开奖历史期号连续、无重复/缺失；昨日开奖已参与复盘。
- 点位写入的目标期正确，昨日点位行未被覆盖。
- 10 个预测模块均正常执行，标准报告与详细报告正常落盘，无未处理异常。
- 命中率面板与回测/扫描结论一致，未把覆盖随机基线的结果说成显著提升。
- 最终给出的集群三元组清单与主攻组一致，格式纯净、可直接复制。

备注
================================================================================
- 快乐8每号单期中出概率恒为 20/80 = 0.25，本系统是结构化描述与复盘工具，
  任何模块都不能改变随机本质，请理性参考、量力而行。
- 超几何基线（20/80 无放回）：20 码期望中 5.0 个（SD≈1.69）；3 码组 P(≥2)=15.26%、
  P(全中)=1.39%；5 码组 P(≥3)=9.67%。多数日子「不中」是结构使然，不是模型失效。
- 10 个模块是描述性统计，不是预测优势；任何「显著」必须先通过预注册样本外验证。
- 所有号码必须由脚本计算，不得由 LLM 自由生成；若引入生成器，先做卡方/熵/有效多样性检验。
- 如需 Excel 报表：报告生成后运行 python kl8_excel_export.py。
